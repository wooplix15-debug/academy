# Zoho CRM authorization

Source ID S03

Verified public reference checked 2 October 2026

https://www.zoho.com/crm/developer/docs/api/v8/auth-request.html

CRM API authorization uses delegated access tokens. Authorization can be specific to an organization and environment. A token authorized for one production organization is not automatically usable for a sandbox or another organization. Match scopes and environment to the exercise.
