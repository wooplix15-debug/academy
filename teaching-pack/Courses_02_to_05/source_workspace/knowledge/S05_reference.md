# Creator form workflow events

Source ID S05

Verified public reference checked 2 October 2026

https://help.zoho.com/portal/en/kb/creator/developer-guide/workflows/create-and-manage-form-workflows/articles/understanding-form-workflows

Creator form workflows respond to record and form events. Validation before submission differs from post submission behavior. Supported actions vary by event and form type. Verify workflow order and event restrictions when writing exact lab steps.

This is a brief reference note, not a full lesson or owner approved academic policy. Exact steps require current trainer verification.
