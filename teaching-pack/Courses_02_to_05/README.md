# Trainer guides · Courses 2–5

These offline guides use the editable source at the repository root. Edit `curriculum`, `data/catalog.json`, `materials/lesson_plans`, `materials/trainer_keys` or `materials/assessment_bank_v2.csv`, then run `python3 teaching-pack/Courses_02_to_05/build_guides.py` from the repository root. Generated HTML and resource copies stay in this folder.

`resources/datasets` and `resources/worksheets` contain synthetic class materials, not production imports. Keep the trainer edition separate from learner copies because it contains answer guidance. Rehearse product steps in the selected account edition before teaching.
