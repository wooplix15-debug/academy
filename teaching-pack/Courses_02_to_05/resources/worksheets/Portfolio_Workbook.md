# Learner portfolio workbook
Copy the CSV templates before each assignment. Blank actuals mean not run. Do not replace them with expected results.
## Prediction sheet
Module ID, input ID, predicted result, reason, observed result, evidence reference, difference, correction, retest result.
## Design decision sheet
Requirement ID, alternatives considered, chosen design, business reason, platform dependency, failure consequence, reviewer decision.
## Debugging sheet
Smallest failing input, expected behavior, observed behavior, suspected cause, controlled change, regression cases, final evidence.
## Handover sheet
Operation, owner, steps, expected result, failure indicator, recovery, escalation, last rehearsal date, peer result.
## Reflection
Explain one assumption you changed, one failed case you repaired and one remaining limitation. Use a fresh independent input so the trainer can check transfer of learning.
