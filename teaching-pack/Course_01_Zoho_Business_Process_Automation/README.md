# Course 1 Trainer Draft

Open `Course1_Teacher_Field_Guide.html` in a current browser. It works offline; links to official Zoho help need internet. Use the chapter navigation, search, print button, completion boxes and expandable answer notes. The local progress boxes stay in this browser.

`meridian_synthetic_leads.csv` contains fictional practice records only. Use it for data-quality, deduplication and import-planning exercises. It is not a production-ready Zoho import file; trainers should confirm the target fields, required columns, assignment options and edition in the actual training organization.

The pack follows the 18 chapters in the Wooplix Academy Zoho Business Process & Corporate Automation syllabus. Meridian Supply, records and classroom activities are proposed fictional teaching content. Product feature availability and screen steps must be rehearsed in the current account before class. Suggested teaching notes and answer guidance are drafts for trainer improvement.

No external libraries are required to regenerate the HTML: run `python3 build_course1.py`.
