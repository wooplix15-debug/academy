# Wooplix Academy teaching-pack exports

Open `START_HERE.html` for the five course guides. The guides work offline after you download or clone the repository. The HTML files include chapter navigation, search, print controls, practical teaching content and trainer guidance. Keep these as trainer editions; the trainer answers are visible in the guide.

The repository-root `curriculum`, `data`, `materials` and `knowledge` folders are the editable source for Courses 2–5. Run `python3 Courses_02_to_05/build_guides.py` from this folder to regenerate their standalone guide pages and resource copies. Course 1 is authored in `Course_01_Zoho_Business_Process_Automation/build_course1.py`; run it from that course folder to rebuild its guide. Product behavior and account access must be rehearsed before class.

The content review is in [`../CONTENT_REVIEW.md`](../CONTENT_REVIEW.md). Course 1 still needs owner-approved duration and assessment terms. These drafts do not claim official vendor certification, employment or client outcomes.
