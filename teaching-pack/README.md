# Wooplix Academy teaching pack

Open `START_HERE.html` in a browser and select a course. Each guide is a local HTML file with chapter navigation, search, print controls, teaching content and trainer answer guidance. The Wooplix partner badge is included.

## Courses

1. Zoho Business Process & Corporate Automation — 18 chapters; course duration remains for Wooplix to set.
2. Zoho Creator Deluge and Integration Developer — 12 weeks, 72 hours.
3. AI and Agentic Business Automation Builder — 10 weeks, 60 hours.
4. Corporate AI and Automation Discovery Workshop — 2 weeks, 12 hours.
5. Zoho CRM Implementation Practitioner — 10 weeks, 60 hours.

The four course guides include the 36 source lesson plans and trainer answer keys, assessment question banks, synthetic datasets and worksheets. Course 1 includes its Python builder and synthetic lead file. The other four include `source_workspace` and `build_guides.py`; edit their catalog, lesson Markdown or answer keys, then run the builder from `Courses_02_to_05`. Course 1 content is authored in `Course_01_Zoho_Business_Process_Automation/build_course1.py`; rerun it from that folder to rebuild the guide. Keep the matching badge image beside each guide.

## Review notes

This is an editable draft library, not a public course promise. Product menus, account editions, integrations and API limits change; trainers must rehearse current behavior. The included Deluge create example is disabled by default and has not been executed in a connected Zoho editor. All classroom records are synthetic. Source S01 is Wooplix strategic context, not technical product evidence. Pass thresholds, attendance rules, duration for Course 1 and certificate wording require owner confirmation.

The four guides follow the local course workspace titles and hours. The Google Docs and public website were not changed.
