## Course overview

Build an evaluated knowledge assistant and a bounded draft generation workflow for a business use case. This program combines explanation, guided practice and a business scenario that you can use to demonstrate the skills you have learned.

## Who should join

Zoho developers, automation practitioners and technical corporate teams.

## Before you join

Basic business process and spreadsheet skills. A Python or JavaScript bridge is required for the coded track; a supervised workflow track can use no code tools.

## What you will build

Build a Wooplix style Academy assistant that drafts a cited lesson or knowledge answer and proposes a reviewed change. Your project evidence includes use case brief, knowledge manifest, retrieval design, prompt and schema, draft workflow, 20 evaluation cases, cost log, permission design and demonstration.

## Skills you will practice

- AI use cases and limits
- Prompt design and structured output
- Business workflows
- Knowledge preparation
- Retrieval and cited answers
- Tools and bounded agents
- Evaluation and adversarial cases
- Operations and cost
- Capstone workflow build
- Builder demonstration and defense
