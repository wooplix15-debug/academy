# Contributing to the Academy workspace

This is a draft content repository. Make focused changes in a branch and keep the source syllabus, lesson plans, assessments, worked examples and website copy aligned.

Before proposing a curriculum change:

1. Identify the course and module IDs affected.
2. State the learner outcome, source references and assumptions.
3. Check the live and independent practice time against the catalog.
4. Update matching assessment and capstone evidence requirements.
5. Record product edition and technical review needs; mark unobserved behavior clearly.
6. Add the impact and reviewer decision to the team registers.

Use fictional or permission-cleared examples. Never commit API keys, passwords, private client records, private approval histories or learner submissions. Do not mark a draft approved because an automated check passed; a trainer and academic reviewer still own their decisions.
