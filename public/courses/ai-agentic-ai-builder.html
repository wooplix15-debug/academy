FINAL PROJECT

Northstar Distribution Sales Knowledge Assistant

Build an assistant that answers product and policy questions from approved content, retrieves permitted CRM context and drafts a follow-up note or task.

What you will produce

  • Task brief, comparison with a process that does not use an agent and architecture.
  • Versioned knowledge sources, citations and access rules.
  • Structured responses and validated tool contracts.
  • Correct handling of missing, ambiguous, conflicting and outdated information.
  • Human approval enforced before record changes or outbound messages.
  • Tests for unauthorised access, malicious source instructions and tool failures.
  • Held-out evaluation covering answer quality and action correctness.
  • Comparative quality, latency and cost results.
  • Trace evidence, version records and support documentation.

How learning is assessed

Demonstrate the assistant against a separate evaluation dataset. Review covers source accuracy, tool actions, permissions, human approval, quality, latency and cost. Each learner explains a failure case and shows how it is handled.
