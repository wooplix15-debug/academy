AI & Agentic AI Builder

Design an evaluated knowledge assistant and a bounded AI workflow for a business task, with human review and clear limits.

WHO IT’S FOR

Zoho developers, automation practitioners and technical corporate teams.

WHAT TO BRING

Basic business-process and spreadsheet skills. The coded track uses Python or JavaScript; a supervised workflow track can use no-code tools.

COURSE PROJECT

A knowledge assistant that returns cited answers and proposes a reviewed content change.

COURSE SYLLABUS

What you’ll
learn and practise.

Open a module to see its focus and practical work. Delivery dates, fees and account access are confirmed with Wooplix for each cohort.

01AI use cases and limits+

select a measurable automation use case; distinguish generation from deterministic execution.

Topics: Language model basics; Business task analysis; Accuracy and verification.

Practice: Compare three academy use cases and select one with an observable success measure.

02Prompt design and structured output+

write an input and output contract; test a prompt against examples.

Topics: Task context and examples; Schemas; Missing information behavior.

Practice: Generate a lesson outline from approved topics with required fields.

03Business workflows+

separate proposal from execution; map exception and review paths.

Topics: Triggers and stages; Human review; Deterministic checks.

Practice: Design an assignment draft workflow with a trainer review step.

04Knowledge preparation+

classify usable source material; keep source and permission metadata.

Topics: Cleaning and sanitization; Chunking; Versions and access labels.

Practice: Convert three synthetic academy notes into indexed knowledge records.

05Retrieval and cited answers+

retrieve relevant context; explain when the assistant should abstain.

Topics: Search and embeddings concepts; RAG; Citations and relevance.

Practice: Answer five questions using only the supplied knowledge set.

06Tools and bounded agents+

define an allowed tool contract; constrain action proposals.

Topics: Tool inputs and outputs; Planning and state; Allowlist and permissions.

Practice: Implement or simulate course lookup and draft lesson tools.

07Evaluation and adversarial cases+

design realistic evaluation cases; measure task success and failure.

Topics: Golden examples; Injection attempts; Human and automated evaluation.

Practice: Build a 20 case evaluation set including five failure or adversarial cases.

08Operations and cost+

measure usage and latency; plan bounded retries and cost limits.

Topics: Tokens and request logging; Timeouts and retry policy; Quality versus cost.

Practice: Measure a small controlled workflow and design a per run budget.

09Capstone workflow build+

connect approved knowledge and generation; stage a reviewable update.

Topics: Draft generation; Validation; Version history.

Practice: Build the Academy assistant and test a curriculum update request.

10Builder demonstration and defense+

demonstrate success and safe failure; explain limitations and maintenance.

Topics: Evaluation review; Practical defense; Support handover.

Practice: Demonstrate ten capstone scenarios and explain five remaining evaluation cases.

PRACTICAL WORK

A knowledge assistant that returns cited answers and proposes a reviewed content change.

Project evidence

How learning is reviewed

Guided labs, evaluation results, capstone evidence and a practical demonstration that includes safe failure cases.
