STUDENT AND TEAM REFERENCE

Live lab verification

Use this checklist before following a product-specific exercise in a shared training environment.

1. Confirm the environment

Record the product, edition or plan, data centre, organisation label, test account and reviewer. Do not use a production organisation or real client data for course practice.

CheckRecord before starting
Product contextProduct name, edition/plan and data centre
AccessUser role, profile, permissions and enabled features
DataSynthetic dataset and its reset method
ReferenceOfficial page URL and date checked

2. Verify the exercise

  1. Confirm the current menu route and feature availability.
  2. Perform the action with synthetic data.
  3. Capture the expected result and the observed result separately.
  4. Test one denied, missing-data or recovery case where the lesson requires it.
  5. Record what changed and how the environment can be reset.

3. Verify technical claims

For API, integration and AI exercises, confirm the current endpoint or SDK version, scopes, authentication method, API limits, regional domain, model availability and pricing assumptions. A documented example is not evidence that it ran in your organisation.
