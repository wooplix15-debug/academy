# AAB-M09 Capstone workflow build
Version 0.2 | Team review required | Synthetic teaching case

## Purpose
- Connect approved knowledge and generation
- Stage a reviewable update

## Prerequisite and capstone contribution
Use the previous module evidence as input: AAB-M08

Save this module evidence in the same course portfolio: Draft artifact, change report and evaluation results.

## Explain the concept
An academy update must identify affected outcomes, hours, assessments and website claims. A reviewable change preserves evidence and binds approval to the exact candidate version.

## Demonstration and sample input
Request: add timeout-after-commit teaching to ZDV-M09. The change report points to lesson, assessment, contract and capstone tests; it does not silently add required hours.

## Live teaching sequence
- Retrieve prior learning: 15 minutes
- Explain and predict: 30 minutes
- Trainer demonstration: 35 minutes
- Guided build: 75 minutes
- Break: 15 minutes
- Failure and recovery tests: 40 minutes
- Evidence review and exit check: 30 minutes

## Guided lab
1. Use the included agent dry run to inspect context.
2. Submit one lesson request when model access is configured.
3. Check sources and expected outcomes.
4. Review changed paths and hashes.
5. Approve one local artifact explicitly.
6. Keep published materials unchanged until authorized.

## Expected result
One candidate lesson plus an impact report. Offline dry run proves context and validation only; it does not prove live generation quality.

## Negative test
Edit the draft after approval preparation. The hash check must reject stale approval.

## Recovery test
Regenerate review metadata for the new version and rerun content checks.

## Independent practice
Revise a course duration and produce an active-cohort migration note before adoption.

Budget: 120 minutes. Use 15 minutes planning, 75 building and testing, 30 documenting.

## Submit and assess
Draft artifact, change report and evaluation results.
- Update preserves existing evidence
- Changed files are identified
- No automatic credential or external write occurs
